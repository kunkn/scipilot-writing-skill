# Scientific Paper Tense Guide

中译英和英文论文润色时，必须根据句子在论文中的功能选择时态。

| 论文内容 | 推荐时态 |
|---|---|
| 普遍事实、领域共识 | 一般现在时 |
| 目前存在的问题 / 研究空缺 | 一般现在时 |
| 某篇前人论文具体做了什么 | 一般过去时 |
| 引言中介绍本文研究内容 | 一般现在时为主 |
| 实验步骤、仪器、参数设置 | 一般过去时 |
| 数值计算具体操作 | 一般过去时 |
| 公式、理论关系、物理机制 | 一般现在时 |
| “图 X 显示……” | 一般现在时 |
| “实验观察到了……” | 一般过去时 |
| 本文已经得到的具体结果 | 一般过去时 |
| 结果说明的普遍规律 | 一般现在时 |
| 结论中的研究工作回顾 | 一般过去时 |
| 结论中的科学意义 / 适用性 | 一般现在时 |
| 未来工作 | 一般将来时或一般现在时 |

## 判断顺序

不要先看中文动词形式，而应先判断句子的论文功能。

例如：

“图 4 表明……”
→ 描述图本身
→ 一般现在时
→ Figure 4 shows ...

“实验中观察到了……”
→ 已完成的实验观察
→ 一般过去时
→ We observed ...

“该现象表明系统存在……”
→ 对结果所体现规律的解释
→ 一般现在时
→ This phenomenon indicates ...

“我们采用 0.1 V 的步长增加直流电压。”
→ 已完成实验操作
→ 一般过去时
→ We increased the DC voltage in steps of 0.1 V.
